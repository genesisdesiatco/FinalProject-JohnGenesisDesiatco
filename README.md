## About the Project
InsightHub Analytics is a demo business website showcasing modern front-end web development — semantic HTML, external CSS, Flexbox layouts, a responsive design that adapts to phones and desktops, and an interactive contact form.

## Pages
| Page | File | Purpose |
|------|------|---------|
| Home | `index.html` | Hero, services overview, why-us, call-to-action |
| About | `about.html` | Mission, values, and team |
| Services | `services.html` | Detailed service cards + process |
| Contact | `contact.html` | Contact form with multiple input types |

## Technologies & Concepts
- **HTML5 semantic elements** — `<header>`, `<nav>`, `<section>`, `<footer>`
- **External CSS** — one shared `style.css` linked by every page
- **CSS selectors** — type, class, id, descendant, grouping
- **Flexbox** — navigation bar, card grids, split sections
- **Responsive design** — media queries for tablet (≤820px) and mobile (≤480px)
- **HTML Forms (Ch5)** — text, email, tel, select, radio, checkbox, textarea, submit/reset, required validation
- **CSS variables, gradients, transitions, hover effects**
