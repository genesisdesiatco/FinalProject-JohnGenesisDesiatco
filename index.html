How We Built This

InsightHub was designed and developed from the ground up using HTML5, CSS3, and responsive design principles — a hands-on demonstration of modern front-end development.

Challenges we solved:

  • Responsiveness: making every page adapt from phone to desktop — solved with Flexbox and CSS media queries.
  • Consistency: keeping one brand identity across pages — solved with a single shared external stylesheet and CSS variables.
  • Engagement: letting visitors reach us easily — solved with a validated, multi-input contact form.
